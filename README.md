# Yandex Music -> yt-dlp (Chrome-расширение)

Chrome-расширение помогает сформировать команду [yt-dlp](https://github.com/yt-dlp/yt-dlp) для треков, открытых на странице Яндекс Музыки.

Расширение не скачивает музыку само. Оно только собирает ссылки на треки, добавляет выбранные параметры и копирует готовую команду в буфер обмена.

## Требования

### yt-dlp

Установи актуальную версию `yt-dlp` обычным способом для своей ОС:

```bash
yt-dlp --version
```

### Известная проблема yt-dlp с Yandex Music

Актуальная проблема Yandex Music на стороне `yt-dlp` отслеживается здесь:

https://github.com/yt-dlp/yt-dlp/issues/4432

## Функционал

- Работает на страницах `https://music.yandex.ru/` и `https://music.yandex.com/`.
- Поддерживает:
  - страницу одного трека;
  - альбомы;
  - популярные треки исполнителя.
- Парсит треки на открытой странице без учета текущего плеера.
- Показывает список найденных треков и позволяет выбрать нужные.
- Формирует команду `yt-dlp`.
- Копирует команду в буфер обмена.

## Установка

1. Скачай файлы расширения.
2. Открой `chrome://extensions`.
3. Включи `Developer mode`.
4. Нажми `Load unpacked`.
5. Выбери папку с файлами расширения.

При обновлении локальной копии расширение нужно перезагрузить на странице `chrome://extensions`.

## Как пользоваться

1. Открой страницу с треками на Яндекс Музыке.
2. Нажми на иконку расширения.
3. При необходимости введи `Yandex Music token`.
4. Выбери нужные треки.
5. Нажми `Copy command`.
6. Вставь команду из буфера обмена в терминал и выполни ее.

## Формат команды

Без токена расширение формирует команду такого вида:

```bash
yt-dlp "https://music.yandex.com/album/8617026/track/57331286"
```

Если в интерфейсе указан `Yandex Music token`, команда будет включать `--extractor-args`:

```bash
yt-dlp --extractor-args "yandexmusic:token=secret" "https://music.yandex.com/album/8617026/track/57331286"
```

Формат `--extractor-args` описан в README `yt-dlp`: https://github.com/yt-dlp/yt-dlp#extractor-arguments

Токен хранится в `chrome.storage.session`: он доступен до перезапуска браузера или расширения и не сохраняется в постоянное локальное хранилище.

## Опции

### Yandex Music token

Добавляет к команде:

```bash
--extractor-args "yandexmusic:token=secret"
```

Токен нужен, если `yt-dlp` требует авторизацию для конкретного трека или страницы.

### Remove track ID from filename

Если включено, расширение добавляет шаблон имени файла:

```bash
-o "%(artist)s - %(track)s.%(ext)s"
```

### Use Firefox cookies

Добавляет флаг:

```bash
--cookies-from-browser firefox
```

Нужно только если сервис требует авторизацию через cookies или скачивание не работает без них.

Примечания:

1. Нужно быть авторизованным в Firefox под своей учетной записью сервиса.
2. Использование cookies может требовать закрыть Firefox перед запуском `yt-dlp`.
